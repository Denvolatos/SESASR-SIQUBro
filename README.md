## 1️⃣ R01 — Bump&Go controller / Bump&Go 控制器

**EN** — The robot always drives straight ahead. When the LiDAR sees a wall closer than 0.5 m, it stops, compares the free space on the left and on the right, and turns towards the more open side using the odometry yaw (90° in simulation; on the real robot it stops turning as soon as the way is free). The same code runs on the real TurtleBot3 with its own parameter file (`config/real_robot.yaml`).

**中文** — 小车一直往前走；激光雷达发现前方 0.5 m 内有墙时停下，比较左右哪边更空，用里程计的偏航角转向更空的一侧（仿真里转 90°；真车上前方一空出来就停止转向）。同一份代码在真车上运行，使用自己的参数文件（`config/real_robot.yaml`）。

```bash
ros2 launch lab02_pkg bump_and_go.launch.py              # simulation (start the Lab02 world first) · 仿真，需先启动 Lab02 场景
ros2 launch lab02_pkg bump_and_go.launch.py robot:=real  # real robot · 真车
```

Final code in the Lab02 maze: goal reached after 10 turns in 220 s; odometry error vs ground truth 0.069 m at the end, 0.073 m maximum. On the real robot the speed limit is 0.15 m/s: at 0.22 m/s it hardly drove forward.
最终版代码在 Lab02 迷宫：转弯 10 次、220 秒到达终点；里程计相对真实位置的误差结束时 0.069 m，最大 0.073 m。真车速度上限为 0.15 m/s：0.22 m/s 时基本不前进。

## 2️⃣ R02 — EKF localization / EKF 定位

**EN** — An extended Kalman filter estimates the robot pose. It predicts at 20 Hz with the velocity motion model, using v and ω from `/odom`, and corrects the estimate with the range and bearing of each landmark it sees. With `fusion:=true` the state also contains v and ω, which are corrected by `/odom` and `/imu`. The result is published on `/ekf`.

**中文** — 用扩展卡尔曼滤波估计小车位姿：以 20 Hz 用速度运动模型预测（v、ω 取自 `/odom`），每看到一个地标就用它的距离和方位修正。`fusion:=true` 时状态里还包括 v、ω，由 `/odom` 和 `/imu` 修正。结果发布在 `/ekf`。

```bash
ros2 launch turtlebot3_ignition lab04.launch.py      # simulation world (Mac: ignition) · 仿真场景
ros2 launch lab04_pkg ekf.launch.py                  # Task 1: state [x, y, θ]
ros2 launch lab04_pkg ekf.launch.py fusion:=true     # Task 2: state [x, y, θ, v, ω]
ros2 launch lab04_pkg ekf.launch.py robot:=real      # Task 3: real robot, landmarks on /camera/landmarks
```

Simulation, 150 s runs, Bump&Go moving the robot (position RMSE against the ground truth): / 仿真，每次 150 秒，用 Bump&Go 让车动（相对真实位置的位置 RMSE）：

| Run / 实验 | `/odom` | `/ekf` |
|---|---|---|
| Task 1 | 0.018 m | 0.010 m |
| Task 2 | 0.020 m | 0.010 m |

On the same recorded data, Task 2 reduced the heading error by about 20–30 % but did not improve the position. These numbers come from one simulated run each. / 在同一份数据上回放时，Task 2 的航向误差小约 20–30%，位置没有改善。以上数字各来自一次仿真运行。

| Trajectory / 轨迹 | Task 0: velocity motion model samples / 运动模型采样 |
|---|---|
| ![EKF trajectory](docs/images/ekf_sim_trajectory.png) | ![motion model](docs/images/ekf_task0_motion_model.png) |

Tools in `src/lab04_pkg/scripts/` / 工具：`task0_models.py` (Task 0 plots, Jacobians with sympy) · `evaluate_ekf.py` (plots, RMSE, MAE) · `replay_filters.py` (both filters on the same bag) · `run_sim_experiment.sh`.

**Replay a real-robot bag / 回放真车数据**（to try other parameters without a new experiment · 不用重做实验就能换参数试）:

```bash
ros2 bag play --clock 1000 --remap /ekf:=/old_ekf -- path/to/rosbag
ros2 launch lab04_pkg ekf.launch.py robot:=real use_sim_time:=true
```

Record `/camera/landmarks` and `/imu` too on the real robot, otherwise the bag cannot be replayed. / 真车上也要录 `/camera/landmarks` 和 `/imu`，否则无法回放。

**Real robot / 真车：** not run yet; the landmark coordinates of the real arena still have to be set in a landmarks file. / 还没跑；真实场地的地标坐标需要写进地标文件。
